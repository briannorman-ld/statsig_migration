# Statsig Documentation

> Official documentation for Statsig feature flags, experimentation, analytics, Warehouse Native, SDKs, APIs, and AI products.

Statsig Feature Gates are feature flags. Statsig Cloud processes hosted event data; Warehouse Native runs analysis against data in the customer's warehouse.
Use Docs MCP for targeted, read-only public documentation retrieval. Authenticated Statsig MCP accesses product resources according to the user's account permissions.
Prefer current SDKs for new implementations. Verify plan requirements, lifecycle status, and availability on the linked live page before making recommendations.
AI Experimentation is Early Access and is not accepting new customers. Use Docs MCP or `/api/content/<slug>` for targeted retrieval; use `llms-full.txt` only as an offline full-corpus resource.
